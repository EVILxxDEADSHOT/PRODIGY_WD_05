# Weather Web Application

This web application fetches and displays the current weather conditions based on the user's location or a manually inputted city name.

------------------------------Features---------------------------------------

- **Search by City**: Enter a city name to get weather details.
- **Use Current Location**: Fetch weather data based on the user's current geographic location.
- **Weather Details**: Displays temperature, weather description, humidity, and wind speed.
 Technologies Used

  -------------------------HTML---------------------------------
Structure of the web page.
- **CSS**: Styling for a clean and modern look.
- **JavaScript**: Fetching data from the API and updating the UI.
- **OpenWeatherMap API**: For real-time weather data.
